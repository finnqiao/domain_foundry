source registry

Guidance enters through a license fence.

Every source has a tier, allowed-use policy, license, retrieval date, freshness window, and topics. Unknown or incompatible rights block copying; reference-only sources may support paraphrased facts and patterns.

principle registry

Compact rules, executable checks.

A principle is accepted only when it links sources, names the evidence a build must carry, and names release checks. The rules are reusable; their application is vertical-specific.

vertical derivation

See a source become a product decision.

The same general principles yield different schemas and experiences because the practice, workloads, and domain evidence differ. No branch in the compiler checks for “sourdough,” “cards,” or “Japanese.”

review ownership

No generator grades its own homework.

Automation catches structure and regressions. Human owners remain explicit for domain correctness, interaction quality, licensing judgment, security threat review, and assisted-technology checks.

open contribution model

Grow the repository without turning it into folklore.

Contributions are reviewable data: a source record, scoped evidence atoms, principle or vertical pattern, fixtures, and an independent evaluation case. Editorial authority and generator behavior stay separate.

source: id: stable_identifier tier: authoritative | reviewed_implementation license: SPDX-or-documented-reference allowed_uses: [reference_facts, paraphrase] retrieved_at: YYYY-MM-DD freshness_days: 180 evidence: claim: one falsifiable statement locator: section / object / line applies_to: [workload, entity, view] evaluation: authored_by: independent_reviewer input: realistic held-out task expected: observable outcome
Maintenance loop

Scheduled freshness audit → stale-source review queue → supersede or reapprove → replay affected derivations → rebuild impacted goldens → publish a receipt. Source updates never silently rewrite existing owned apps.

Creative retrieval

Search across workflows, information structures, interactions, and visual systems—not screenshots alone. Remix records the exact borrowed fragment and the resulting spec diff.
