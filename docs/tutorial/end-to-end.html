00 / walk it yourself

One loop. Two ways in.

Everyone talks in Claude, Telegram, or the little app. Developers can do the same loop in a terminal. Same coffee. Same records on your machine.

  1. Install once

    Ask a techy friend, or paste this yourself. After that you never need the terminal again.

    # macOS / Linux — one line
pipx install domain-foundry-core domain-foundry-mcp
domain-foundry setup
domain-foundry serve

    Then open http://127.0.0.1:8787 — Today, Your passions, Inbox.

  2. Talk where you already chat

    In Claude Desktop → Settings → Developer → Edit Config, paste this and restart:

    {
  "mcpServers": {
    "domain-foundry": {
      "command": "domain-foundry-mcp",
      "args": ["--home", "~/.domain_foundry"]
    }
  }
}

    Or text a Telegram bot you created with @BotFather. You only need one of: the app, Claude, or Telegram.

  3. Optional: add a key so it understands how you talk

    Without a key you still get a simple log you can talk to today. With a key, “track my coffee” picks fields like method, dose, and taste — not a blank journal.

    In the app: Settings → add a DeepSeek or OpenRouter key. A friend who uses Hermes often already has DeepSeek.

  4. Describe the passion, then log a real note

    Say what you actually do. Then say what happened. If it’s sure, it files. If it isn’t, the note waits in Inbox — nothing is thrown away.

    You: track my coffee
Foundry: Coffee is ready. Log one real note and we'll file it.

You: V60 this morning, Ethiopia, 15g in, bergamot and jasmine, rating 8
Foundry: Saved as a brew.

  5. Ask, then fix in one sentence

    Ask what you logged. To change a number, say it plainly — rating = 9 works, and so does “actually it was a 9.”

    You: what was my last brew and how did it taste?
Foundry: Ethiopia V60 — bergamot and jasmine. (from your records)

You: rating = 9
Foundry: Updated. History kept.

  6. Old notes, if you already have some

    In the app: Settings → Sources. Paste a folder, preview where notes would land (changes nothing), then Pull in. Your original files are never moved.

That’s the whole loop. Name it → talk → file or Inbox → ask → fix. Same data if you later open the terminal. Longer no-terminal notes: Use Domain Foundry.

  1. Install from the checkout

    git clone https://github.com/finnqiao/domain_foundry && cd domain_foundry
python3.11 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pip install -e ./adapters/mcp -e ./adapters/telegram -e ./adapters/hermes_agent

    Data lives in ~/.domain_foundry (or DOMAIN_FOUNDRY_HOME): ledger.sqlite + domains.sqlite.

  2. Bring a key (DeepSeek is first-class)

    Hermes users often already have DEEPSEEK_API_KEY in ~/.hermes/.env. Native Google Gemini keys on this machine were rejected; OpenRouter still works as a mix-and-match option.

    export DEEPSEEK_API_KEY=...
export DOMAIN_FOUNDRY_LLM=live
domain-foundry setup --provider deepseek -y
domain-foundry setup --show   # keys redacted

# or one OpenRouter key for many models
export OPENROUTER_API_KEY=...
domain-foundry setup --provider openrouter -y

    setup --provider deepseek writes routine=deepseek-chat, sota=deepseek-reasoner. Env vars beat the config file.

  3. Describe → log → ask → correct → export

    domain-foundry new-domain "log my pour-over coffee brews"
# live design: fields like method / dose / taste. No key → honest simple log.

domain-foundry capture "V60, Ethiopia Yirgacheffe, 15g in, bergamot, rating 8"
domain-foundry ask "what was my last brew and how did it taste?"
domain-foundry correct "rating = 9"
domain-foundry export --json -o /tmp/coffee.json
domain-foundry health

    An off-topic note (“changed the oil in the Civic”) should stay unfiled, not get guessed into coffee. Secrets in a note show as [REDACTED].

  4. Same loop from the app, MCP, or ingest

    domain-foundry serve                 # http://127.0.0.1:8787
domain-foundry-mcp                   # Claude / Cursor stdio
domain-foundry ingest ~/Notes --dry-run

    Writes share one local API. Pack YAML is data, not code — the wizard’s output under ~/.domain_foundry/packs/<name>/ is a fine thing to hand-edit. Full seams: developer how-to.

Proof we ran this. Isolated home, Hermes DeepSeek, coffee designed live (dry-run 10/10), capture applied, car-oil unfiled, Ask cited a brew, rating = 9 applied, export had no key leaks.

04 / it never pretends

Sure, unsure, and oops are different.

Nothing silently disappears. You can look, file, correct, or take the data with you.

✓Sure → in your app

It recognizes a bake, a climb, a brew. The note becomes a record and shows up on the timeline.

?Unsure → kept for you

If it isn’t sure where a note belongs, it saves the words and waits in Inbox. It never throws them away.

↺Oops → say so

“Actually the hydration was 80.” The loaf updates, the old number stays in history, and it remembers next time.

06 / why your agent loves this

Three verbs. That’s the whole loop.

Your agent is a courier for your words — not the source of truth. The records live here, so next week’s chat still knows last weekend’s loaf. With a model, Ask answers in a sentence; without one, you still get the closest records — never a guess from the internet.

01

Log — pass what you said, exactly. Foundry files it as a bake, a climb, a brew.

02

Ask — “when did I last bake something great?” Answers come from your records, with a trail back to the loaf.

03

Fix — “actually it was 80%.” History stays. The same mistake can be caught next time.
